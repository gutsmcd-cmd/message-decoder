# メッセージ解読 / Message Decoder

Paste a messy, typo-filled message (English or Japanese) and see:

- **what it probably says**, rewritten clearly
- **a one-line summary**
- **anything unclear**, flagged with possible meanings instead of a silent guess

Free, no ads, no login, no API key. Part of [Universe 74](https://gutsmcd-cmd.github.io/universe-74/).

**Live:** https://gutsmcd-cmd.github.io/message-decoder/

The message is sent to the free, keyless [Pollinations.ai](https://pollinations.ai) text API to decode it. Don't paste anything secret.

Vite + TypeScript PWA. Built to the `gh-pages` branch by GitHub Actions.
